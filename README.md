# merchant-workbench-skill

实体商家工作台制作技能包。

结合商品经营和预约服务门店的经验，辅助 Codex 根据商家需要规划、设计、实现、测试和交付手机工作台。包含需求梳理、页面主题、经营功能、财务口径、库存会员、角色权限、手机适配和交付检查。

这是方法与参考资料，不包含完整工作台源码、真实门店数据、服务器账号或密钥。功能需要根据具体项目实现和验证。

## 安装

将下面这段话发送给支持 Skill 的 Codex：

```text
请使用 $skill-installer，从 GitHub 仓库
brunacavalcanticastro416-hub/merchant-workbench-skill
安装路径 skills/merchant-workbench。
安装后检查 SKILL.md 和 references 下的五个文件是否完整。
```

如果安装后暂时没有显示，请重新打开 Codex 或新建对话。

## 使用

```text
使用 $merchant-workbench。请先读取 SKILL.md 和 references 下的五个参考文件，再根据我的门店需求规划和制作手机工作台。
```

Skill 是供 AI 参考的流程和资料，不会自动获得店铺数据或服务权限；业务、费用和部署按实际需求确认。
