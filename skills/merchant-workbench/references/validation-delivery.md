# 验证、上线与交付

## 上线前可观察验收

按交付清单在隔离数据环境验证真实行为，而非仅检查按钮可见：登录退出；每类账号服务端可读写边界；跨账号共享、跨门店隔离；收入/支出/成本/退款统计；商品多件销售、库存扣减和退货回库；会员充值、余额支付、退款或次卡；服务预约、冲突、员工工资提成（如项目包含）；导出、图片和操作日志。针对网络中断、重复点击、并发与保存结果不确定进行验证。核对现金口径和日期范围，避免双计或双扣。

检查 320–440 CSS 像素、常见 iPhone 及安卓的不同高度、纵横屏、浏览器栏、输入键盘、表单滚动、导航、字体缩放、安全区域和 reduced-motion。屏幕模拟不等于真机、iOS 主屏幕启动和真实网络体验；有条件时让用户用实际设备验收。不得承诺完全无卡顿、绝不丢数据、所有手机绝对兼容。

## 现网与迁移

盘点代码、数据库、文件、身份认证、权限、依赖和目标环境；核对快照、恢复方式和目标版本。使用模拟数据或隔离环境演练；迁移前安排写入暂停与最终增量核对，保护原系统和旧访问方式，验证记录数量、关键金额、文件、角色与功能，再由用户按约定验收。失败时按已准备的方式回退。切换、停用、删除或清空真实数据需要明确授权；测试用数据也要确认范围及备份。是否取消原环境依赖各项验证，不要因为登录成功就断言迁移完整。

## 交付

说明已完成/未完成功能、真实测试设备和结果、账号与权限、访问/添加主屏幕方式、统计口径、导出与备份恢复范围、故障联系方式、服务器与域名费用、续费及服务边界；有需要提供带例子的员工和老板使用手册。不要把截图或数据源中的身份、密钥、真实品牌/人物图片打进对外的模板。上线地址、账号创建、域名及收费等以实际实施与商家约定为准。
