# 账号、数据与权限

与商家逐项明确角色矩阵：谁可查看总收入、支出、利润、工资、客户资料、会员、库存及成本；谁可新增、修改、退款、删除、恢复、导出、管理账号。老板是否只读、员工能否录成本但不能看汇总利润，均由商家决定。页面按权限呈现，后端对每次读写、字段和业务动作做授权；不要把前端隐藏当成安全边界。

共享门店数据需明确店铺范围，涉及多商家必须实施服务端隔离并用跨店测试证明；不要假设共用一个环境自动隔离。记录实际服务人和录入人；对财务删除等重要操作记录操作者、时间、对象、必要的前后值，并限制日志的查看与保留。删除、退款、撤销、恢复及关联会员或库存需要明确业务约束，不得破坏关联或伪造可恢复能力。

采用事务、版本控制或等效机制防并发覆盖；重复提交使用幂等或有明确核对机制。会话退出、账号禁用、上传图片与导出均遵循当前权限。断网或保存结果不确定时显示“待核对”，先确认再重试，避免重复销售或充值。避免本机旧数据跨账号自动合并、过时页面恢复已清空数据；迁移或恢复需检查版本与数据来源。

客户照片、密码、真实账号和真实流水不要放进案例包或日志。支持密码安全设置，不在聊天、脚本参数、截图或示例中泄露明文密码；避免硬编码真实密钥和店铺标识。
